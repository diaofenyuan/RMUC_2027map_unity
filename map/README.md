# RMUC 2027 二维地图包（雷达用）

本目录提供 RoboMaster 2027 赛季超级对抗赛比赛场地的二维俯视地图资源，面向雷达点云匹配、
区域掩膜与可视化使用。底图取自官方规则手册图 4-1，按围挡内缘展开并去除白边，整幅严格对应
28 m × 15 m 比赛区，输出分辨率 2800 × 1500（100 px/m）。同一套像素坐标下另附红/蓝半场
着色图、三色高度掩膜与叠加预览。

本包是**二维名义参考**，不是规则书 G 坐标，也不是裁判系统坐标；未经过实机定位精度验收。
使用前请阅读[数据边界](#数据边界与适用范围)。

## 几何与坐标约定

| 项目 | 约定 |
| --- | --- |
| 名义比赛区 | 28 m × 15 m（围挡内缘） |
| 栅格尺寸 | 2800 × 1500 px |
| 输出尺度 | 100 px/m，即 1 px = 10 mm |
| 画面范围 | 整幅即围挡内缘，无白边、无围挡外框、无额外留边 |
| 朝向 | 官方图 4-1 朝向：红方在左（制高点在左上），蓝方在右（制高点在右下） |

场地二维参考坐标 `(x, y)`（单位 m，`x ∈ [0, 28]`，`y ∈ [0, 15]`）到像素 `(u, v)` 的换算：

```text
u = (1 - x / 28.0) * 2799
v = (1 - y / 15.0) * 1499
```

角点对应关系：

| 场地坐标 | 像素坐标 | 图像位置 |
| --- | --- | --- |
| `(0, 0)` | `(2799, 1499)` | 右下 |
| `(28, 0)` | `(0, 1499)` | 左下 |
| `(28, 15)` | `(0, 0)` | 左上 |
| `(0, 15)` | `(2799, 0)` | 右上 |

该坐标仅为根据官方图 4-1 与图 4-5 的 28000 × 15000 mm 尺寸线建立的**二维名义参考**。它不等价
于规则书 G 基准，也不等价于实机裁判系统坐标；跨系统对表前必须自行核对锚点。

### 底图来源与精度限制

主底图由官方手册图 4-1（981 × 559）按围挡内缘四点作单应展开，重采样至 2800 × 1500。源图
围挡内缘约为 871 × 465 px，折合约 31 px/m；100 px/m 是输出栅格尺度，不代表源图具备厘米级
细节。底图是规则示意图的透视校正与重采样结果，不是 CAD 正交投影，边缘和局部结构存在插值
误差。需要严格几何时，请以本仓库 `Project/Assets/Field/field_geometry_m.ply` 的 CAD 网格为准。

官方效果渲染中包含用于展示的机器人等动态物体，它们不属于场地常驻几何；掩膜按审查结果将
相关机械占位列为黑色排除区，底图本身仍保留其像素。

## 高度掩膜

`rm2027-map-mask.png` 为 RGB 三色图，只允许以下三种像素值，无抗锯齿与过渡色：

| 颜色 | RGB | 语义 |
| --- | --- | --- |
| 绿 | `(0, 255, 0)` | 高于约 0.22 m 的抬升平面：中央高地、装配区、制高点平台 |
| 蓝 | `(0, 0, 255)` | 名义约 0.15–0.22 m 的抬升平面：堡垒台面、梯形高地、道路（含起伏路段凸起） |
| 黑 | `(0, 0, 0)` | 地面，以及墙体、机关占位、隧道上下层歧义等保守排除区 |

掩膜遵循“非黑 = 非地面层”的既有约定，用于选择像素所属的映射平面，**不是逐像素绝对高度**。
坡面随所属平台归类，道路凸起仍归道路颜色；黑色不能一律解释为已确认可行驶地面。

生成方式：在 Unity 2022.3.62f1 中按人工审查后的实例与表面角色，对官方 CAD 网格
（`field_geometry_m.ply`）完整栅格化 87,160 个三角面；不采用俯视最高 Z、不采用首命中、
不做稀疏顶点膨胀。栅格化结果无损转换为官方图 4-1 朝向后与主底图逐像素对齐。

| 统计项 | 数值 |
| --- | --- |
| 蓝色像素 | 1,304,251（31.05%） |
| 绿色像素 | 879,860（20.95%） |
| 非黑（抬升）像素占比 | 52.0026% |
| 非黑区域并集面积 | 218.4111 m² |
| 参与栅格化的三角面投影面积 | 236.4815 m²（含重叠，未扣除排除面） |

二维掩膜无法消除隧道上下层的投影歧义；隧道区域的点云归属需由使用者结合高度与上下文判断。

## 红/蓝半场着色图

`rm2027-map-red.png` 与 `rm2027-map-blue.png` 只对己方半场做轻度色偏：红方为左半场，蓝方为
右半场。三张底图逐像素几何一致，**不旋转、不镜像、不改变坐标定义**，仅用于显示区分。涉及
匹配或标注时，请使用 `rm2027-map.png` 或掩膜，不要依赖色偏图。

`rm2027-map-mask-overlay.png` 为 `0.55 × 底图 + 0.45 × 掩膜` 的预览图，只用于人工检查掩膜
与底图是否对齐，不建议作为匹配输入。

## 雷达使用建议

1. **点云投影**：按上文公式把点云平面坐标投到 100 px/m 栅格，或反向把地图栅格化为占用/高度
   先验。投影前需自行完成雷达安装外参与场地锚点标定。
2. **分层处理**：先用掩膜区分地面与抬升平面，避免把高地、堡垒、道路的点云压到同一平面。
   黑色区域包含墙体与排除区，不能直接当作地面。
3. **降采样**：底图源分辨率约 31 px/m，匹配时建议降采样至 50 px/m 或更低，避免把插值细节
   当成真实几何。掩膜可按最近邻降采样，保持三色语义。
4. **显示与匹配分离**：红/蓝图仅用于显示；匹配、标注与误差统计统一使用主底图或掩膜。
5. **外部标定自备**：本包不包含雷达内参、外参、时间同步或实机标定结果。

## 数据边界与适用范围

1. **二维名义参考**：坐标与尺度来自官方规则图与尺寸线，未经回放或实机验证，`map_ready = false`。
2. **非规则 G 坐标**：不得直接与裁判系统坐标、其他队伍的内部坐标混用。
3. **非 CAD 正交投影**：底图是规则示意图的单应校正结果，几何精度低于 CAD 网格，不能作为
   尺寸测量或精密配准的唯一依据。
4. **掩膜非真值**：颜色表示映射平面归属，不是实测高度；隧道上下层与机关占位仍存在歧义。
5. **不含传感器标定**：不提供相机内参、雷达外参、时间同步或场地实测点。
6. **精度结论无效**：本包不得作为建图精度、定位精度或融合精度的验收依据。

## 获取方式

完整克隆（包含 Unity 工程）：

```bash
git lfs install
git clone https://github.com/diaofenyuan/RMUC_2027map_unity.git
```

只取二维地图、不下载 382 MB 的 LFS 模型：

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/diaofenyuan/RMUC_2027map_unity.git
```

Windows PowerShell：

```powershell
$env:GIT_LFS_SKIP_SMUDGE = "1"
git clone --depth 1 https://github.com/diaofenyuan/RMUC_2027map_unity.git
```

克隆后地图位于 `map/`，LFS 指针文件保持未拉取状态，不影响本目录使用。
